# Лабораторная работа №1

## Описание задания

1. Развернуть 3 разные LLM из разных семейств
2. Подготовить 3 тестовых запроса под разные типы задач
3. Сгенерировать ответы каждой LLM в двух режимах
4. Сохранить все ответы и провести эмпирический анализ

## Использованные технологии и модели

Работа проводилась на MacBook Air M4, 16 ГБ RAM.

**LLM:**
* qwen3.5:4b (3.4 ГБ) – отключал ризонинг
* llama3.2:3b (2.0 ГБ)
* gemma3:4b (3.3 ГБ)

**Фреймворки:**

Использовался Ollama.
Его преимущества
* Поддерживает GPU Apple Silicon и устанавливается обычным приложением для macOS.
* Выполняет обязательное требование лабораторной — OpenAI-совместимый REST API
* Позволяет использовать компактные квантованные модели

## Результаты работы

Гиперпараметры для всех трёх задач:

* **A (базовый):** параметры сэмплирования не передавались, использовались дефолты движка.
* **B (тюнинг):** `temperature=0.3`, `max_tokens=250`.
* Для Qwen в обоих режимах reasoning отключён: `reasoning_effort=none`.

### Генерация

*Промпт*

```
Ты — специалист службы поддержки интернет-магазина. Напиши вежливый ответ клиенту на русском языке.

Жалоба клиента: «Здравствуйте! Я заказал наушники две недели назад, но заказ до сих пор не пришёл. В приложении статус не обновляется. Очень расстроен, жду ответа!»

Требования к письму:
1. Поприветствуйте клиента и поблагодарите за обращение.
2. Признайте проблему и извинитесь за доставленные неудобства.
3. Объясните, что заказ задерживается, и пообещайте разобраться.
4. Сообщите, что мы проверим статус отправления и вернёмся с ответом в течение 24 часов.
5. Завершите письмо вежливо.

Объём — примерно 120–150 слов. Тон — дружелюбный и профессиональный, без канцелярита.
```

### Классификация

*Промпт*

```
Ты — классификатор новостных текстов. Определи тему каждого текста и присвой ему ровно одну метку из списка:

["World", "Sports", "Business", "Sci/Tech"]

Тексты:
1. «Сборная России по хоккею обыграла соперника со счётом 4:2 в финале турнира.»
2. «Центробанк повысил ключевую ставку на 0,5 процентного пункта.»
3. «NASA объявило о новой миссии по исследованию спутника Юпитера.»
4. «Переговоры по климатическому соглашению завершились в Женеве без итогового документа.»
5. «Компания Apple отчиталась о росте выручки на 8% за квартал.»

Формат вывода — по одной строке на текст:
<номер>: <метка>

Никаких пояснений, только метки.
```

*Ожидаемый ответ*

```
1: Sports
2: Business
3: Sci/Tech
4: World
5: Business
```

### Извлечение

*Промпт*

```
Ты — ассистент, который извлекает структурированные данные из описаний товаров. Прочитай текст описания и извлеки из него информацию строго в формате JSON.

Схема JSON:
{
  "название": строка,
  "категория": строка,
  "бренд": строка или null,
  "цвет": строка или null,
  "цена": число или null,
  "валюта": строка или null,
  "наличие": "в наличии" | "нет в наличии" | null
}

Описание товара:
«Представляем беспроводные наушники SoundMax Pro от бренда AudioWave — чёрного цвета, с активным шумоподавлением и 30 часами автономной работы. Сейчас в наличии, цена 12 990 рублей. Идеальны для спорта и путешествий!»

Правила:
1. Если какого-то поля в тексте нет, ставь null.
2. Не выдумывай данные, которых нет в описании.
3. Выведи только JSON, без комментариев и пояснений.
```

*Ожидаемый ответ (один из допустимых вариантов)*

```
{
  "название": "Беспроводные наушники SoundMax Pro",
  "категория": "наушники",
  "бренд": "AudioWave",
  "цвет": "чёрный",
  "цена": 12990,
  "валюта": "рублей",
  "наличие": "в наличии"
}
```

## Выводы

Промпты проверяли не только содержание, но и соблюдение инструкций: объёма письма, фиксированных меток и строгого JSON. Поэтому правильный по смыслу ответ мог нарушать формат.

* В генерации писем наиболее удачные ответы получились у Gemma. Llama смешивала языки; увеличение лимита с 250 до 500 токенов устранило обрезание, но не языковые ошибки. Настройка гиперпараметров не улучшила качество во всех задачах.

* В классификации все модели правильно определили 5 из 5 меток, однако Llama в режиме B нарушила формат ответа.

* При извлечении данных Qwen выполнила требования, Llama пропустила категорию, а Gemma добавила Markdown-ограждение.

## Инструкция по запуску

Если сервер ещё не запущен через приложение Ollama, запустить его в отдельном
терминале и оставить работающим:

```bash
ollama serve
```

В другом терминале скачать модели (если их ещё нет):

```bash
ollama pull qwen3.5:4b
ollama pull llama3.2:3b
ollama pull gemma3:4b
```

Проверить скачанные модели и модели, загруженные сейчас в память:

```bash
ollama list
ollama ps
```

Основные прогоны лабораторной выполняются через REST API существующим `run.py`,
а не интерактивным `ollama run`. Из корня репозитория, в Python-окружении
с установленными `requests` и `PyYAML`, после настройки `source/config.yaml`:

```bash
python projects/da-tereshin/lab1/source/run.py
```
